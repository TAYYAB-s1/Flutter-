# Project Evaluation Criteria

| Component | Weightage |
|------------|------------|
| UI/UX Design | 20% |
| Functionality | 30% |
| Code Quality | 20% |
| Documentation | 10% |
| GitHub Activity | 15% |
| Innovation | 5% |

## GitHub Activity Requirements

- Minimum 2 commits per week
- Consistent repository activity
- Meaningful commit messages
- Proper version control usage
